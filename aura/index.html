AuraDesign v1.0
Design Language

AuraDesign

一个克制、成熟的界面设计语言。

设计语言 约 8 分钟阅读 Web · 桌面 · 移动

界面是一种噪音。它的价值，取决于它愿意在多大程度上保持安静。

我们为什么需要另一套设计语言

今天的设计系统，大多在争夺注意力。饱和度拉满的主色、层层堆叠的阴影、 大到夸张的圆角、像彩蛋一样的动效——这些不是设计，而是对用户注意力的透支。

当一个界面需要用户花三秒钟去判断「这个按钮能不能点」时， 设计就已经失败了。AuraDesign 是一个反方向的尝试。 它相信界面应该像空气：存在，但不打扰。

这套语言最初诞生于几个个人项目的迭代中，后来逐渐沉淀为可复用的规则。 它不追求让人「哇」，只追求让人「嗯，就是这样」。

六条原则

如果只记住六件事，那就是这些。

01
用灰度思考，用蓝色决定

界面中 90% 的元素应该只由灰度构成。蓝色只留给那些真正需要用户 「做决定」的地方——主操作、当前选中、需要被注意的状态。 强调色不是装饰，是信号。

02
不用绝对的黑色与白色

纯黑与纯白是屏幕上的极端值，对比度过高会让眼睛疲劳。 用 #23262b 代替 #000， 用 #f2f3f5 代替 #fff， 留出一点呼吸的空间。

03
用线条划分，而不是色块

阴影很浅，边框很细。结构感来自间距和对齐， 而不是大面积背景色。一个页面里不应该出现两个以上互不相干的背景色块。

04
圆角是克制的

6px 到 12px 覆盖了几乎所有场景。超过 16px 的圆角会让人联想到 玩具或糖果，而不是工具。例外只有模态框和头像，可以使用 12–14px。

05
动效服务于理解

所有过渡都在 120–360ms 之间，使用缓出曲线。 动效的目的只是告诉用户「发生了什么」，而不是让他觉得「好酷」。 不做弹跳，不做旋转，不做超过 1.04 倍的缩放。

06
尊重内容

当内容和装饰冲突时，装饰让路。所有装饰性元素——光晕、网格、噪点、 渐变——都应该降低到 10% 以下的不透明度，或者干脆去掉。

颜色是怎么来的

整个系统只有七个核心令牌。它们不是随手挑的， 而是在几十次对比度检查和屏幕测试之后留下来的最小值。

间距与圆角

基础单位是 4px。常用的间距值有 8、12、16、20、24、28、32、48、64。 不要使用 6、10、14 这样的非 4 倍数值——它们会破坏对齐的节奏。

圆角阶梯： 4px 用于徽标和标签， 6px 用于小按钮和输入框， 8px 用于标准按钮、输入框、卡片， 10–12px 用于大卡片和面板， 14px 用于模态框。

动效

动效是 AuraDesign 里最容易被忽视、也最容易被做坏的部分。 原则很简单：如果动效不能让用户更快理解发生了什么，就不该存在。

微交互（悬停、按下）用 120–180ms；组件出现与消失用 200–260ms； 布局变化用 280–360ms。统一使用 cubic-bezier(0.22, 1, 0.36, 1) 缓出曲线。 不做弹跳，不做旋转，不做超过 1.04 倍的缩放。

什么时候不该用 AuraDesign

这套语言是为工具型界面设计的。它不适合：

  • 品牌落地页——它们需要更强的情绪表达，需要更大的颜色对比。
  • 儿童、教育类产品——它们需要更活泼的色彩和更圆润的形状。
  • 数据可视化——需要依靠颜色区分维度时，应该另建一套可视化色板。
  • 游戏界面——游戏需要更强的沉浸感和视觉冲击。

在这些场景里使用 AuraDesign，你会觉得它「不够有性格」。 那不是它的失败，而是它的边界。

写在最后

最好的界面是让人记不住的界面。用户不会记得你的按钮有几个像素的圆角， 他只会记得「刚才那个操作挺顺的」。

AuraDesign 不会让任何一个人惊叹。但如果它能让界面少一点干扰、多一点安静， 那它就已经完成了自己的任务。

Getting Started

引入 aura.css

一份 CSS 文件，一次引入，立刻获得整套 AuraDesign 风格。

单文件 CSS 约 6 分钟上手 零构建依赖

你不需要复制令牌、不需要手写按钮样式。 把 aura.css 放进项目，在 <head> 里引一次， 然后在 HTML 里使用组件类名即可。

文件放在哪里

推荐把 aura.css 放在项目的 css/ 目录下， 与页面入口文件保持相对路径清晰。
你可以前往 github.com/linxianlww/linxianlww.github.io 获取 css 文件。 

project/
├── index.html
├── css/
│   └── aura.css        ← 引入这一份即可
└── js/
    └── theme.js        ← 可选：深色模式切换

如果你把 CSS 放在其他位置，只需保证 <link> 的 href 指向正确路径。

第一步：在 <head> 中引入

在页面的 <head> 中引入 aura.css。 它应该排在业务样式之前，方便后续按需覆盖。 

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport"
        content="width=device-width, initial-scale=1" />
  <title>我的页面</title>

  <!-- AuraDesign 样式 -->
  <link rel="stylesheet" href="css/aura.css" />

  <!-- 可选：业务样式，写在 aura.css 之后 -->
  <link rel="stylesheet" href="css/app.css" />
</head>
<body>
  <!-- 页面内容 -->
</body>
</html>
顺序很重要：aura.css 先引入， 业务样式后引入。这样你在 app.css 里写的规则 可以覆盖默认样式，而不需要提高选择器权重。

第二步：直接使用组件类名

引入之后，所有组件类名都可以直接使用。例如按钮、输入框和卡片： 

<div class="card">
  <div class="card-title">项目名称</div>
  <div class="card-text">简短说明文字。</div>

  <input class="input" type="text"
         placeholder="请输入内容" />

  <div style="margin-top:12px;display:flex;gap:8px;">
    <button class="btn btn-primary">保存</button>
    <button class="btn btn-ghost">取消</button>
  </div>
</div>

类名不需要额外包装，也不需要初始化脚本。组件库 Tab 中的每个示例 都可以直接粘贴到页面里使用。

第三步：可选资源

aura.css 不依赖任何外部文件。但以下两项可以提升完整效果， 按需引入：

字体

主字体 Inter，等宽字体 JetBrains Mono。 不引入也能正常使用，只是会回退到系统字体。 

<link rel="preconnect"
      href="https://fonts.googleapis.com" />
<link rel="preconnect"
      href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600&family=JetBrains+Mono:wght@400;500&display=swap"
      rel="stylesheet" />

图标

组件里使用的图标来自 Font Awesome 6。如果不引入， 图标位置会留空，但组件布局不受影响。 

<link rel="stylesheet"
      href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css" />

第四步：深色模式

深色模式已经写在 aura.css 里，通过 html.dark 生效。你只需要在页面加载时决定是否加上这个类名。

把下面这段脚本放在 <head> 中—— 注意是在 aura.css 之后、<body> 之前。 提前执行可以避免页面先以浅色渲染再切换的闪烁。 

<script>
  (function () {
    var saved = localStorage.getItem('aura-theme');
    var prefersDark = window.matchMedia(
      '(prefers-color-scheme: dark)'
    ).matches;

    if (saved === 'dark' || (!saved && prefersDark)) {
      document.documentElement.classList.add('dark');
    }
  })();
</script>

如果你需要提供手动切换入口，再加一个按钮和几行事件处理： 

<button class="icon-btn"
        id="themeToggle"
        aria-label="切换主题">切换</button>

<script>
  document.getElementById('themeToggle')
    .addEventListener('click', function () {
      document.documentElement.classList.toggle('dark');

      var isDark = document.documentElement
        .classList.contains('dark');

      localStorage.setItem(
        'aura-theme',
        isDark ? 'dark' : 'light'
      );
    });
</script>

一个完整的最小页面

把前面几步组合起来，就是下面这个文件。保存为 index.html， 与 css/aura.css 放在同一目录下，即可直接打开。

  <!-- 1. 先执行深色模式判定，避免闪烁 -->

    (function () {

        '(prefers-color-scheme: dark)'
      ).matches;
      if (saved === 'dark' || (!saved && prefersDark)) {
        document.documentElement.classList.add('dark');
      }
    })();
  </script>

  <!-- 2. 引入 AuraDesign -->
  <link rel="stylesheet" href="css/aura.css" />
</head>
<body style="padding:40px 24px;">

  <div class="aura-container">
    <div class="card">
      <div class="card-title">AuraDesign</div>
      <div class="card-text">
        一个克制、成熟的界面设计语言。
      </div>

      <div style="margin-top:16px;
                  display:flex;
                  gap:8px;">
        <button class="btn btn-primary">开始使用</button>
        <button class="btn btn-ghost"
                id="themeToggle">切换主题</button>
      </div>
    </div>
  </div>

  <!-- 3. 可选：手动切换主题 -->
  <script>
    document.getElementById('themeToggle')
      .addEventListener('click', function () {
        document.documentElement.classList.toggle('dark');
        var isDark = document.documentElement

          'aura-theme',
          isDark ? 'dark' : 'light'
        );
      });
  </script>
</body>
</html>

这段示例只依赖 aura.css，不需要任何构建工具， 也不需要额外引入字体或图标。

常见问题

样式没有生效怎么办？

依次检查三件事：第一，<link> 的路径是否正确； 第二，浏览器开发者工具中是否成功加载了 aura.css； 第三，是否被业务样式覆盖。最常见的原因是路径写错， 或者 aura.css 被放在了业务样式之后。

深色模式不生效？

检查 html 上是否真的有 dark 类名， 以及初始化脚本是否放在 <head> 中执行。 如果脚本放在 <body> 底部，页面会先渲染浅色， 再切换深色，出现明显闪烁。

可以改强调色吗？

可以。在业务样式里覆盖变量即可，不需要改 aura.css： 

/* 放在业务样式中，aura.css 之后 */
:root {
  --accent:      #7c3aed;
  --accent-soft: rgba(124, 58, 237, 0.10);
}

html.dark {
  --accent:      #a78bfa;
  --accent-soft: rgba(167, 139, 250, 0.14);
}

注意保持强调色与背景的对比度不低于 4.5:1， 深色模式下的强调色通常需要更亮。

类名冲突怎么办？

aura.css 的类名（如 .btn、 .card、.input）比较短，可能与现有项目冲突。 两种处理方式：

  • 给 aura.css 里的类名统一加前缀，例如 .aura-btn， 再同步修改 HTML 中的类名；
  • 在业务样式中提高选择器优先级，覆盖掉冲突的部分。

需要引入 JavaScript 吗？

不需要。所有组件都是纯 CSS。只有深色模式切换需要几行 JS， 而是否使用切换入口完全由你决定。
